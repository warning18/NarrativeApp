# The 33 Journey glyphs and the final gap set
`png/<key>.png` (33, 16x16 PNG8, original style: 1 px ink `#0A0807`, 2 tones, light top-left): one for each distinct Material icon of `lib/widgets/journey_glyph.dart`; `material_map.json` maps each key to the `Icons.*` it replaces (casino and casino_outlined share the die). Fixed colours (no theme tint). The idle motions in code (sway, bob, pulse...) are unchanged.
`../pixellab-gap/` (drop-ins, 16x16): `skills/` edict_of_silence, glass_reflection, hex_of_ill_luck, rotting_mark, shroud_reflection (to `assets/icons/skills/`), `items/` boss_trophy, fate_coin (to `assets/icons/items/`), `elements/` lightning, ice, holy, dark, none (common-gem container in the element colour with a cream glyph, for the element marks that are Material today). Sheet: `docs/art/boards/journey-gap-icons.png`. Generator `journey_gen.py` (repo root). 0 generations. Not wired. Weakest glyph: `fighter` (a fist at 14 px); say if it needs another pass.
