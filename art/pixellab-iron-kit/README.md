# Old-iron UI kit and separate environment decorations (the user's direction)
**Cost: 0 generations**, hand-drawn in code (`iron_gen.py`, repo root). Sheets: `docs/art/boards/iron-kit.png` (each environment on a panel and two buttons, light and dark grounds, real size and 3x) and `iron-kit-pieces.png` (every piece, stretched by its 9-slice, 2x). `anchors.json` has every size, 9-slice margin and decoration anchor for UX-2.
## ui/ (all PNG RGBA, 9-slice margins in anchors.json)
`panel_dark`, `panel_parchment` (24x24, slice 8: iron band with rust and pitting, rivets, 2 px ink), `hud_panel` (16x16, slice 5, thinner for the fight HUD), `dialog` (32x32, slice 12, thicker band, corner studs, parchment field), `button_{primary,secondary}_{normal,pressed,disabled}` (24x16, slice 6; primary is bronze, secondary iron), `tab` (20x14, slice 6), `chip` (16x12, slice 5), `divider` (24x6, slice 8, rivet caps), `corner` (12x12 bracket for a corner overlay).
## env/ (separate transparent sprites, 3 variants per anchor so repeats do not look stamped)
Environments: `wilds` (vines, moss, leaves), `dunes` (sand drifts, pebbles), `frost` (snow caps, icicles), `coast` (rope, barnacles, salt crust), `ash` (soot, embers), `city` (soot stains, a lantern on a hook), `sacred_void` (candle wax drips and a candle, violet cracks). Per environment: `<env>_top_<0..2>.png` (32x10, hangs from the top edge), `<env>_bottom_<0..2>.png` (32x8, rises from the bottom edge), `<env>_corner_<0..2>.png` (16x16, top-left; flip for the other corners). Each sprite carries its own 1 px ink so it reads on the iron; layered over the frame's edge (overlap 4 px when tiling), never baked into it. On small controls (buttons) use the corners only.
Not wired. UX picks the environment from the zone/biome in code.
