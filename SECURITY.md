# Security Policy

## Supported Versions

This project ships a single rolling release rather than maintaining multiple
long-term branches — see [CHANGELOG.md](CHANGELOG.md) for the current
version. Security fixes land on the latest release only.

## Reporting a Vulnerability

Please **do not** open a public GitHub issue for security vulnerabilities.

Instead, use GitHub's private vulnerability reporting for this repository:

1. Go to the **Security** tab
2. Click **Report a vulnerability**
3. Include as much detail as you can — steps to reproduce, impact, and the
   affected files or version

You should receive an acknowledgement within a few days. Once a fix is
confirmed, it will be released and credited in the CHANGELOG unless you'd
prefer to remain anonymous.
