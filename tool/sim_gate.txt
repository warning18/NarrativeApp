# What CI leaves out of a pull request that cannot move it (QA: item 3 of
# docs/qa/qa-improvements-2.md, and item 4 of docs/proposals/qa-ideas-round-3.md).
# Read by tool/shard_tests.py and by test/qa_sim_gate_test.dart.
#
# `group <name>`: starts a group; each group has its own gated files and paths.
#
# `gated <file>`: a test file in test/ that a group holds back. On a pull
# request that changes none of the group's `trigger` paths, CI leaves these
# out of its shards; on main, and on any pull request that changes a trigger
# path, it runs them.
#
# `trigger <prefix>`: a changed file whose path starts with the prefix may
# change what the group's tests measure. A prefix ending in `/` is a folder.
#
# `ignore <prefix>`: a changed file under this prefix never counts, though a
# trigger covers it (a folder inside a broad trigger that the group's tests
# do not read: qa_sim_gate_test.dart checks that they do not).
