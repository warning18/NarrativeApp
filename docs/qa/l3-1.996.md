# L3 regression and quality review: v1.992 to v1.996

QA, 2026-11-23. Asked by the Manager for the user: the L3 on request plus a quality review.
Basis: main v1.992 (`f528428d`) for the audits and the first two suite runs, v1.996.0 (`c2cfc18f`)
for the third suite run, the simulator batch and the fight read-through. Previous L3:
[1.888.0](l3-1.888.0.md). No `lib/` change; one version-less docs and tests PR.

Review protocol (Manager, three passes): pass 1 found, pass 2 re-ran each finding on the code or in
a picture, pass 3 re-read the v1.993 to v1.996 seams (fight nameplate, dice data) and looked for
what the first two passes missed. Findings below are only the ones that reproduced.

## Result

Pass, **no blocker, no crash, no lost progress, no soft-lock found**. Four findings, all Low or
Low to Medium (issues #1098 to #1101, label `qa`). Suite is green three times with no flaky test.

Notes, not findings:

- A potion drunk in a fight stays spent after the app is killed; the fight itself is not saved, so
  a kill in the middle of a fight returns the player to the menu, Continue, and the scene before the
  fight, minus the potion, with no XP or loot. Nothing sticks. Pinned by `test/qa_midfight_kill_test.dart`.
  If the user wants a mid-fight save, that is Core's call.
- `lib` has no app-lifecycle observer: the session is written on every change, so pausing and
  resuming loses nothing; there is nothing to resume.
- `data/strings_audit.py`: 3,831 app-string keys, 0 used but undefined. Some 1,900 keys have no
  literal use in `lib/` (many are built at run time with a prefix); not verified one by one,
  a candidate for Cleanup, not a bug.

## Proposals, ranked (impact × cost)

1. **Quick win, UX, S**: let a long foe name take two lines on the nameplate (or drop "BOSS" to the
   row under it) so it is never under about 9 px; finding 3. Needs pictures first.
2. **Quick win, UX, S**: inventory equipment tiles at 1.3×: allow the grid its height, break names
   at spaces (findings 1, 2 together, one afternoon).
3. **Quick win, Narrative, S**: "Harbour" (finding 4).
4. **Needs the user's choice, Core, M**: a mid-fight save (today the fight and its XP are lost on a
   kill; only potions stay spent). Probably not worth it for a game of short fights.
5. **Core, S**: raise the three boss figures still under the curve by 5 or more (tear_herald 29/35,
   claimant_morrow 31/40, void_archon 44/50) only if the user wants the late game gentler; the
   Tower and mid-game are in band.
