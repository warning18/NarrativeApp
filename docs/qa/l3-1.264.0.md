the more reliable one, is the same as before (36.7% against 37%), and so is
every profession within 3 points. A seed's stream of rolls shifts whenever
the story graph gains choices (this cycle added 31 scenes), which is
enough to move a 100-run batch by a few points. The balance picture of the

failed attempts of any chapter), melee classes trail the casters by about 15

## Gamedata cross-reference audit

names (enemies, items, dice, quests, shops, skills and spells, zones, NPCs,

Also green in the full suite: `qa_data_refs_test` (skill, tree, merge,
enemy-move, loot and effect references; French skill text), `qa_strings_test`
(string table and `tr()` keys), `qa_story_fr_test` (the story graph's bare

## Guards added

`test/qa_real_font_layout_test.dart` (this PR) loads the app's bundled fonts
and checks the level-up pop-up at 360 and 320 px in English and French, and
the home shell's bar and rail at a landscape phone, a tablet and a phone, for
overflow. The default test font (Ahem) is far wider than the real ones, so a
layout can only be judged with them loaded. A failing run of a dialog test
can take several minutes to finish reporting in this environment, so a red
result from it is worth reading the first overflow line of.
