# L3 regression: 1.274.0

Head tested: `b0218e6` (#202), v1.274.0+310, 2026-10-13. **Android only**
(releases are Android only; nothing was run for iOS). The previous L3 was
1.264.0 (`ef2e38b`); the comparison point for this one is the
[1.270.0 baseline](l3-prep-1.270.0.md) taken on `211d2ce`, so the effect of
chapter 5 (#196) is not mixed with the rest.

## Result

Pass. No regression found. Four findings on PRs under review, none of them
on `main`; two layout notes carried over (below).

| check | result |
|---|---|
| `dart format --output=none --set-exit-if-changed .` | clean (2.5 s) |
| `flutter analyze` | no issues (14 s) |
| full `flutter test` (the simulator tests and the `qa_` guards included) | **2216 passed, 10 skipped, 14m50s** (1.264.0: 2141, 14m32s; 1.270.0: 2191, 14m49s) |
| simulator, 100 runs, seed 7, 4 goals, 20 runs per profession | 100/100 reach an ending in chapter 8 |
| simulator, 800-run check (seeds 11 and 23, 400 each) | 800/800 reach an ending |
| story coverage, 300 runs per batch, seed 7 | exploring runs reach 411 of 426 scenes (96%), random 392 (92%); 0 scenes statically unreachable |
| gamedata cross-reference | green: `qa_data_refs_test`, `qa_strings_test`, `qa_story_fr_test` and the other `qa_` guards pass in the full suite |
| screens changed since 1.264.0 | read, measured with the bundled fonts at 360 and 320 px in English and French where a layout was at stake (below) |

The first full run had two tests report "did not complete"
(`interactive_die_test`, `skill_face_limit_test`: the loadout screen) while I was
running other Flutter work on the same machine; both pass in 8 s alone, three times
in a row, and the whole suite passes on the clean rerun above. Same cause as the
slow-reporting failures noted in the 1.264.0 L3: a loaded machine, not a
change in the code. For a timed L3 nothing else should run alongside.

The 10 skipped tests are my layout guards waiting for UX's #203
(`qa_real_font_cards_test`, `qa_ch7_hub_layout_test`, one flag each,
`skipUntilFixPack`). With the flag off on #203's head all pass.

Reading it. The 800-run check, the reliable one, is the same as the baseline
(39.8% against 40.0%) and every chapter and profession is within 1 to 2
points of it: nothing moved between 1.270.0 and 1.274.0 in how the game
plays, as expected (the PRs between them are story data, moods, the travel
data and the Edit Mode tool). Against 1.264.0 the change is chapter 5
(#196): 21% to 31%. The 100-run batch moved by 3 points (38.1% to 41.3%), which
is the noise a changed story graph gives that batch (this cycle added 11 scenes and
the moods). The balance picture holds: chapter 7 (17%) is the lowest, melee
classes trail the casters by about 20 points (warrior 30%, cleric 54%).
