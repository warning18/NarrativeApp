# Shop sizes (picture first, no version yet)
The user: "Shop should be a bit bigger or character smaller when combined." `shop-sizes-360.png`: three shops (the Weaponsmith with a 48 px keeper, the Blind Beggar's stall and the Shieldwright's hall with 64 px keepers) at 360 wide (a 328 px strip), in three rows: today; (a) the stall 1.25x (about 80% of the strip's width) with the keeper as now; (b) the stall as now with the keeper 0.8x, scaled about its feet so the counter still hides the legs.
How it is scaled: the strip's pixel is 328/150 = 2.19 screen pixels for the stall and the keeper alike today, drawn nearest-neighbour; (a) makes the stall's pixel 2.73, (b) the keeper's 1.75. None is a whole step: on a 360 phone a whole step (2x = 192 px stall, 3x = 288 px) is a bigger jump than the user asked for, so the picture keeps the in-between sizes with hard edges; a whole step for the keeper (1.5x of the 1x frame = 1.5 px per art pixel) is not whole either. If the user wants crisp, I would take (a) at 2.5x on the stall (a 240 px stall, 73% of the strip) and the keeper at 2x (as today) rounded to whole device pixels.
`ShopLayers(shopId, stallScale:, keeperScale:)` already takes both numbers, so the build is a default change.
