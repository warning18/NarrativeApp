# Chibi dark-medieval UI frames: three kits and environment accents (picture first, nothing wired)
Sheet: `docs/art/boards/chibi-frame-kits.png` (light and dark grounds, real size and scaled). Files: `art/pixellab-chibi-frames/<kit>/` (`panel.png` 24x24, 9-slice with 8 px margins; `button.png` and `button_pressed.png` 24x16, 6 px margins; `corner.png` 12x12; `texture.png` 16x16 tileable), `nine_slice.json`, generator `frames_gen.py`. **Hand-drawn in code, 0 generations.**
- **A, stitched leather (recommended):** dark plum leather, a 2 px ink outline with chamfered corners, a gold stitch line, a rust button that drops and darkens when pressed. Closest to the hero's chunky ink-outlined look and to the existing dark panels.
- **B, forged iron:** cold riveted steel plate, a brown button with rivets. Heavier, colder.
- **C, carved bone:** parchment plate with a double border and a green button. The light option, for the book-like screens.
- **Environment accents (for A):** six corner ornaments and a stitch tint, so a screen changes lightly with where the player is: city (a battlement, gold stitch), wilds (leaves, green), coast (waves, teal), ash (a flame, ember), frost (a snow crystal, ice blue), sacred/void (a star, violet). A panel keeps its dark leather and only the stitch colour and the corner change, so the dark base stays one design. The environment id would come from the zone/biome in code.
- **Notes:** the kits are a first pass at real size, for choosing a direction; if one is picked, the next step is a polish pass (thicker "chibi" outline on the panels, more ornament variety) and a hand-off with the 9-slice insets for UX-2. PixelLab is not needed for frame kits (the panel pilot already used code); a generation would only add a painted ornament (1 each).
