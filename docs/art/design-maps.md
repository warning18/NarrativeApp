# The Ashen Quarter and the casino: two map versions each (picture first, nothing wired)
Sheets: `docs/art/boards/map-ashen-quarter.png` and `map-casino.png` (today | version 1 | version 2). Files: `art/pixellab-maps/` (`ashen_quarter_{today,v1,v2}.png`, `casino_{today,v1,v2}.png`, `placement.json`, generator `maps_gen.py`). **Hand-drawn in code from the game's own data, 0 generations.** "Today" is a reconstruction from the same data (not a screenshot): the Ashen plan is `assets/gamedata/city_plans.json` (wall, 5 gates, 11 towers, 5 avenues, 5 streets, 2 squares, 5 districts, 171 buildings), the casino is `RoomPlan._casino` in `lib/data/room_plan.dart` (floor, cashier, two VIP rooms, vault, 6 doors, wheel, 6 + 2 tables, bar, stairs, counters, strongboxes).
- **Why drawn from the data:** every wall, door, gate, building polygon and anchor is the plan's own, scaled by a fixed factor (`placement.json`), so pins, taps and the walker line up with no re-fitting. A freely painted PixelLab plate cannot promise that.
- **Version 1, dark ink plate (recommended with the chibi kit A):** ashen-grey ground tinted per district, ink-outlined avenues and streets, brown tile roofs with a light top-left edge, red hall roofs, blue temple roofs with a gold finial, orange stalls, a stone wall with ink-ringed towers and gold-lit gates, ash heaps and dead trees outside. Casino: plank hall with a red carpet to the gold roulette wheel, green felt tables ringed by stools, plum rooms with rugs, gold strongboxes, stone vault.
- **Version 2, warm lantern plate:** the same geometry in a warmer reading: sand ground, cream roads, red-clay roofs and a dark wall for the town; a gilded casino with a black-and-gold tiled hall, burgundy rooms, brass walls and four chandeliers.
- **Both keep** the legibility rules: places, doors and paths exactly where the code expects them, no baked text (names stay in code), the 1 px ink and light top-left of the art direction.
- **Optional, costs generations:** a painted texture under the plates (floor planks, roof tiles, cobbles) from `create_image_pixen`, about 2 generations a map (4 total), composited under the same geometry so it still lines up. Not started; the user's round limit is 20 generations and this used 0.
- **Next:** the user picks a version per map; then a polish pass (more ornament variety, props around the squares, a night variant) and a hand-off with the scale and the file names for UX-2.
